# 🎸 Bocchi the Rock! — Novela Visual

Una **novela visual inspirada en *Bocchi the Rock!***

## 📖 Sobre el proyecto

Este proyecto es algo más tranquilo, con lo que cada integrante busca ir aprendiendo poco a poco y sin ningún tipo de presión, es por eso mismo que decidimos hacer una novela visual pues es algo más sencillo y considero idoneo para empezar.

## 🎮 Características

* 💬 Sistema de diálogos.
* 🎭 Personajes y expresiones.
* 🖼️ Escenarios y fondos.
* 🎵 Música y efectos de sonido.
* 🔀 Decisiones durante la historia.
* 📚 Diferentes escenas y rutas narrativas.
* 💾 Sistema de guardado y carga de partidas.
* 🖥️ Interfaz desarrollada con JavaFX.

### Clonar el repositorio

```bash
git clone https://github.com/USUARIO/REPOSITORIO.git
```

Entrar al proyecto:

```bash
cd REPOSITORIO
```

Compilar:

```bash
mvn clean install
```

Ejecutar el proyecto:

```bash
mvn javafx:run
```

## 🌱 Desarrollo

Para mantener organizado el desarrollo, cada integrante debería trabajar en una rama independiente:

```bash
git checkout -b feature/nombre-de-la-funcionalidad
```

Después de terminar los cambios:

```bash
git add .
git commit -m "Descripción de los cambios"
git push origin feature/nombre-de-la-funcionalidad
```

Luego se puede crear un **Pull Request** para integrar los cambios a `main`.
